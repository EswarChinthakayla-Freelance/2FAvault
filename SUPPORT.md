## 2. GitHub Issues & Bug Reports
- **Bug Reports:** If you encountered unexpected behavior or an error, open a [Bug Report](https://github.com/EswarChinthakayla-Freelance/2FAvault/issues/new?template=bug_report.yml).
- **Feature Requests:** If you'd like to suggest an improvement, submit a [Feature Request](https://github.com/EswarChinthakayla-Freelance/2FAvault/issues/new?template=feature_request.yml).

---

## 3. Security Vulnerabilities
If your issue is related to a potential security vulnerability or private data handling:
- **Do NOT open a public GitHub issue.**
- Follow the responsible disclosure guidelines in [SECURITY.md](SECURITY.md).
